Abstract

A reproducible ROS 2 Jazzy workspace for mapping and autonomous navigation of a differential-drive robot in Gazebo Harmonic, built as the base for multi-floor navigation. The robot carries a GPU lidar, an RGB camera and an RGB-D camera, is driven through ros2_control, and is taken through three phases: teleoperation, SLAM mapping and map-based autonomous navigation with Nav2. An elevator world is included for multi-floor experiments.

Pipeline

Teleoperationkeyboard or joystick through twist_mux
MappingSLAM Toolbox, online asynchronous
LocalisationSLAM Toolbox localisation mode on the saved map
NavigationNav2 planning and control to goal poses
  • Robot description. Modular xacro: base with inertial macros, GPU lidar, RGB camera and RGB-D camera, Gazebo diff-drive and joint-state plugins, and a ros2_control hardware interface for a real Arduino-based base.
  • Simulation. Gazebo Harmonic with an empty world and an elevator world; a velocity-mapping node adapts command velocities to the controller.
  • Configuration. Tuned SLAM Toolbox mapping and localisation parameters, Nav2 parameters, twist_mux priorities and RViz layouts.

Quick Start

ros2 launch diffbot_learning sim.launch.py
python3 src/scripts/vel_mapper.py
ros2 launch slam_toolbox online_async_launch.py params_file:=src/config/mapper_params_online_async.yaml use_sim_time:=true
ros2 launch nav2_bringup navigation_launch.py use_sim_time:=true map:=src/maps/map.yaml
